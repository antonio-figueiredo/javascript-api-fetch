Esse é um exercício que resolvi para treinar Javascript.
A resolução consiste em:

1- Consumir uma API e mostrar os resultados na tela.

2- Fazer o mesmo, porém mostrando apenas o resultado do id desejado pelo usuário.

3- Consumir a API e mostrar o resultado na tela de acordo com a empresa que o usuário digitou. 

É um exercício simples mas que me permitiu treinar conceitos de vida real como consumo de API e busca.
